# ミニゲーム集（仮）

『メイドインワリオ』のような、数秒のミニゲームが次々に出てくるゲームです。
メンバー一人一人がミニゲームを作り、このリポジトリに追加していきます。

## 必要なもの

| 項目 | 内容 |
|---|---|
| Unity | **6000.3.22f1**（このバージョンに完全に合わせてください。`ProjectSettings/ProjectVersion.txt` が正です） |
| Git | [GitHub Desktop](https://desktop.github.com/) がおすすめ |
| GitHubアカウント | 管理者にユーザー名を伝えて、Collaboratorとして招待してもらってください |

## はじめかた

1. 招待メールからリポジトリへの招待を承認する
2. GitHub Desktop で `File → Clone repository` からこのリポジトリをクローンする
3. Unity Hub の `Add → Add project from disk` で、クローンしたフォルダを開く
   - バージョンが違うと警告が出ます。指定のバージョンをインストールしてから開いてください
4. 初回は `Library/` の生成に時間がかかります

## フォルダのルール

```
Assets/
├─ Core/          ← 管理者だけが編集（ゲームの土台）
├─ MiniGames/
│   ├─ _Template/ ← ひな形。コピーして使う（準備中）
│   └─ 作者_ゲーム名/ ← 自分のミニゲームはここだけ触る
└─ Shared/        ← 共通素材（追加したいときは管理者に相談）
```

- **自分のフォルダの外は変更しないでください**
- `ProjectSettings/`（Tags / Layers / Input など）や `Packages/`（パッケージの追加）を変えたいときは、管理者に相談してください

## ミニゲームの作り方

準備中です。テンプレートとサンプルができたらここに書きます。

## 提出の流れ

1. `main` から自分用のブランチを作る（例：`nietz/dodge`）
2. 自分のフォルダでミニゲームを作ってコミットする
3. GitHub で Pull Request を作る（チェックリストが表示されるので確認する）
4. レビューを受けて、OKが出たらマージ

`main` には直接pushできません。

## 注意

- このリポジトリは**公開**されています。素材（画像・音楽・フォント）は自作のもの、または公開してよいライセンスのものだけを使ってください
- 大きなファイル（目安：1ファイル50MB以上）は入れないでください
